轻截 LightCapture 首个 GitHub 公开版本。

包含紧凑捕获栏、窗口／区域／全屏截图、可编辑标注、剪贴板图片导入、中英文界面、OCR、图片保存／复制／拼接，以及可选电脑声音和麦克风的 MP4 录屏。

当前版本还包含编辑器「粘贴」按钮、四角展开的全屏截图图标，以及工具栏图标和文字间距调整。

**运行要求：Apple Silicon（arm64），macOS 15 或更新版本。**

下载 `LightCapture-v0.6.21-macOS-arm64.zip` 并解压使用。`SHA256SUMS` 提供安装包校验值；源码可从仓库或 GitHub 自动生成的源码压缩包获取。

发行包采用临时签名，未经 Developer ID 签名或 Apple 公证。截图／录屏需要系统录屏权限，麦克风录音需麦克风权限；更新临时签名版本可能需要重新登记授权。当前无 Intel 构建、自动滚动截图、可编辑工程保存或视频剪辑。

First public GitHub release of LightCapture v0.6.21. Requires Apple Silicon and macOS 15+. The app is ad-hoc signed, not Developer ID signed or notarized. See the repository README and validation notes for details.
